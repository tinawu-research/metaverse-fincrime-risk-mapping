Earlier same-model-reference comparison, kept for provenance.

sensitivity_runs.csv and sensitivity_summary.csv compare each variant with the representative (medoid-seed) K = 11 model.
That comparison base mixes the effect of the specification with seed-to-seed variation (full-corpus K = 11 matched seed similarity is about 0.39), so it cannot separate the two.
Use tables/paired_sensitivity_summary.csv and tables/paired_sensitivity_pairs.csv (same-seed baseline) instead. The two comparison bases are not interchangeable.
